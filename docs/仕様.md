# Windows向け高機能ファイルエクスプローラー 開発仕様書 v3

## AI開発プロンプト

あなたは経験豊富なWindowsデスクトップアプリ開発者です。
以下の仕様を満たす、実用レベルのWindows向け高機能ファイルエクスプローラーを設計・実装してください。

このアプリは **Windows 11 Explorer + 開発者向けターミナル/Git/SVN + macOS FinderのQuick Look + VS Code的な分割/ターミナル操作** を融合したファイルマネージャーを目指します。

## 6. メイン表示モード

**通常の単純リスト表示は用意しない。**

切り替え可能なモード：

### 6.1 階層表示（主要モード）

```text
▾ 📁 Project
  ▾ 📁 src
    ▸ 📁 components
      📄 Button.cs
      📄 Header.cs
    📄 main.cs
  ▸ 📁 assets
  ▸ 📁 tests
  📄 README.md
```

- ファイルとフォルダを同じツリーに表示
- `▸` / `▾` を使用
- `+` / `-` は使用しない
- Lazy Loading
- UI Virtualization
- 非同期列挙
- フォルダに入らなくても下位階層を展開できる

```text

📄 main.cs         2026/09/01 21:32     C#ファイル      12 KB
📄 README.md       2026/08/31 18:20     Markdown         4 KB
```

列候補：

- 名前
- 更新日時
- 作成日時
- 種類

## 11. アドレスバー

Windows 11 Explorer風パンくず。

```text
C: > Users > User > Project > src
```

各階層をクリックして移動。

各階層にドロップダウンを用意する。

例：

```text
C: > aa > 2026 > 05
       ▼
```

`aa` のドロップダウン：

```text
C:\
├─ aa
├─ ab
├─ ac
└─ Documents
```

現在 `C:\aa\2026\05` で `ab` を選択した場合：

- 左クリック → `C:\ab`
- 右クリック → `C:\ab\2026\05`

つまりパスの一部だけ差し替え、下層を維持する。

下層が存在しない場合は安全に処理する。

### URL/パス直接入力

- `Ctrl + L`
- `F6`

でアドレスバーへフォーカス。

1. コンパイル可能なコードを生成する。

5. 既存コードの依存関係を確認する。

9. 非同期処理を適切に使用する。
10. エラー処理を入れる。
11. キーボード操作を重視する。
12. Windows 11のUI/UXを優先する。
13. 可能な限り実際にビルドしてエラーを修正する。
14. 機能追加時に既存機能を壊さない。
15. 外部ライブラリ追加時は採用理由とライセンスを確認する。
16. セキュリティ上危険な実装を避ける。
17. 長時間処理にはキャンセル手段を用意する。
18. 将来の機能追加を考慮した拡張可能な設計にする。
19. 仕様上の曖昧な部分は勝手に簡略化せず、合理的な実装案を提示する。
20. UI操作は可能な限りキーボードでも完結できるようにする。
