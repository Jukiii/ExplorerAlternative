## v1.5.0

### 追加
- **インストーラー**（`ExplorerAlternative-v1.5.0-Setup.exe`）：管理者権限なしでインストールでき、スタートメニュー登録・アンインストールに対応（#32）。zip版も引き続き添付
- ターミナルの **Tab補完**：コマンド名・パラメーター・パスを補完。候補が複数のときは、押すたびに次の候補、Shift+Tabで前の候補（#20）
- **SFTPのリモートファイルのプレビュー**：リモートブラウザの「プレビュー」で、ダウンロードして通常のプレビューで表示（#28の一部）

### 内部
- PaneViewModel・MainWindowを機能ごとのファイルに分割（#34）
- 単体テストを大幅に追加（146件→759件）（#35）
