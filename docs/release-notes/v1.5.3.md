## v1.5.3

運営者（Jさん）が v1.5.2 を試した際の指摘（#36）への対応です。

### 修正
- **ターミナルの同期で、同じ `Set-Location` が延々と入力される不具合**を修正した。フォルダの中のファイルが変わり続けるとき（他のアプリが書き込んでいるリポジトリ等）に、ターミナルへ `Set-Location` が送られ続けていた。同じフォルダの再読み込みでは、同期しないようにした

### 変更
- **タッチパネル**で、指でなぞってスクロールできるようにした
- **Logウィンドウ**の、コミットの変更内容で、追加した行（`+`）は背景を黄緑、削除した行（`-`）は背景を赤にした（Patchの内容確認も同じ）
- 左ペインの「**最近使った場所**」「**よく使う場所**」の表示をやめた（記録は続け、タスクバーのジャンプリストで使う）
- 左右のペインの折りたたみボタンから、「折りたたむ」の文字をなくした（矢印だけ。マウスを載せると「折りたたむ」と出る）
