## v1.5.2

運営者（Jさん）が v1.5.1 を試した際の指摘（#36）への対応です。

### 変更
- **PDFプレビュー**：1ページずつ切り替える方式をやめ、全ページを縦に並べて、普通にスクロールで見られるようにした。ページ数が多いPDFでも重くならないよう、見えている付近のページだけ描く。`PageUp`/`PageDown`・`Home`/`End`でもスクロールでき、画面の上部に「3 / 12」と、いまのページを表示する

### 修正
- **ターミナルの枠が、内容に合わせて勝手に広がり続ける不具合**を修正した。原因は、枠の高さの指定の誤りで、高さが「自動」になっていたこと。あわせて、上端のつまみをドラッグしてもターミナルの高さが変わらなかった問題も直る
