# 0002 ワークスペースに保存する状態の範囲

日付: 2026-10-01 / 対象: 仕様書43章「ワークスペース」/ Issue #25

## 決定

仕様書43章の「保存対象」のうち、次を保存・復元する。次の2つは、保存・復元の対象にしない。

| 項目 | 決定 | 理由 |
| ---- | ---- | ---- |
| ウィンドウの最大化状態 | 保存・復元する（最大化前の大きさ・位置も保存） | 復元して最大化を解除したときに、元の大きさに戻れるようにするため |
| ターミナル（表示・タブ数・Sync・高さ） | 保存・復元する。ただし出力内容・カレントディレクトリ・実行中のコマンドは保存しない | シェルは復元時に新しく起動する。出力を復元しても、実行状態とは一致しないため |
| 階層表示の展開状態 | 保存・復元する | 画面の見た目の復元として自然で、リスクがない |
| 分割ペインの大きさ | 保存・復元する（#23で実装） | — |
| **SSH接続状態** | **保存・復元しない** | 復元時に自動で再接続すると、意図しないサーバーへの接続や、保存済みパスワードの自動入力が起きる。接続は、利用者が明示的に開始する操作にする |
| **Quick Look固定状態** | **保存・復元しない** | 固定は、プレビューウィンドウが開いている間だけ意味を持つ一時的な状態。ワークスペースを読み込んだ時点では、プレビューは閉じているため、復元する対象が無い |
| 選択状態 | 保存・復元しない | 仕様書43章の保存対象に含まれない（お気に入りの「現在パス＋選択状態」は、お気に入り側の機能） |

## ターミナル復元の方針

- **実行中のターミナルは閉じない。** ワークスペースを読み込んでも、実行中の作業（ビルド・SSH接続など）を失わないようにする。保存時にパネルを表示していた場合は、タブが足りなければ追加し、Syncの設定とアクティブなタブを保存時に合わせる。
- 保存時にパネルを隠していた場合は、パネルを隠すだけで、シェルは起動しない。

## 互換性

保存データ（`settings.json` 内のワークスペース）に追加した項目（`IsWindowMaximized`・`Terminal`・`PaneState.ExpandedPaths`）は、すべて省略可能。この機能の追加前に保存したワークスペースも、既定値（最大化なし・ターミナル状態なし・展開なし）として読み込める。
